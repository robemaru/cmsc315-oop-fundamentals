Unit 3 Discussion: List Operations
For this assignment, I worked with Python lists and implemented insertion, deletion, and search operations. I tested these operations at different positions in the list, including the beginning, middle, and end.
My real-world scenario is a task management system. Tasks can be added to a list, removed when they are completed, and searched when a specific task needs to be found. This demonstrates how list operations can be used in a practical application.
Insertion and deletion can require other elements in the list to shift, especially when the operation occurs near the beginning or middle. Searching for a value uses a linear search, meaning the list is checked sequentially until the requested value is found or the end of the list is reached.
I also tested edge cases, such as searching for a value that does not exist and attempting to delete an item using an invalid index. These tests helped demonstrate how the program handles situations that can occur in real-world applications.
Overall, this assignment helped me better understand how Python lists work and how different list operations can affect performance as the list grows.
